🔒 Reveal rule

Predictions remain private until that individual fixture kicks off. At kick-off, everyone's predictions for that match become visible.

🏆 How points work

CORRECT DRAW
4

Correctly predict that the match finishes as a draw.

CORRECT WINNER
3

Correctly predict which team wins.

EXACT SCORE BONUS
+2

Get the exact score as well and add another 2 points.

WRONG RESULT
0

Anything else.

🔥 Double Points (DP)

Every Gameweek, each player can select one fixture as their DP (Double Points) match.

Only that one selected match is doubled — your total Gameweek score is not doubled. Your normal score for the DP prediction is simply doubled:

CORRECT WINNER + DP
6
3 × 2
CORRECT DRAW + DP
8
4 × 2
EXACT WINNER + DP
10
5 × 2
EXACT DRAW + DP
12
6 × 2

A wrong DP prediction still scores 0. You can change your DP selection while the selected fixture is still open. Once your DP match kicks off, the DP is locked for that Gameweek.

⚽ Draw example

Actual: Liverpool 1–1 Chelsea

Predict 1–1 → 6 pts
Predict 2–2 → 4 pts
Predict 0–0 → 4 pts
Predict Liverpool 2–1 → 0 pts

⚽ Winner example

Predict Liverpool 1–0 → 3 pts
